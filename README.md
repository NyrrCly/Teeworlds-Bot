This bot was created by NyrrCly. At the time, I was interested in making a simple bot for DDNet / Teeworlds servers. 

This bot is based on the [teeworlds library](https://github.com/swarfeya/teeworlds-library-ts).

### Functionality

1. [Config](src/configs/config.json)
2. Login System by nicknames
3. Some interesting commands :D

### How to start
1. You need to download [nodejs](https://nodejs.org/en/download)
2. Run: `npm install`
3. Change [configs](src/configs/config.json), add webhook links
4. After this run: `npm run start`
